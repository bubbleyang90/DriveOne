## 发现并修复的边界问题

- OAuth 交换期间不再提前宣称账号已连接
- 断开/切换模式后，迟到的 token 或列表响应无法恢复旧账号或覆盖新视图
- 刷新失败清除本机授权，并保留可理解的错误状态
- 响应在取消后才到达、下载尚未读取就因过大被拒绝，都会关闭响应流
- 下载队列等待真正的清理结束；并发同名下载不覆盖，失败不留下最终文件
- 在网络等待期间被替换的目录会在写入前再次检查
- Fetch 自动解压时，不再把压缩 Content-Length 当成解压后文件长度
- 不支持断点续传时，拒绝意外的 206 / Content-Range，防止把半个文件标成完成
- Google 导出不重复追加已有扩展名；受限下载能力在后端与界面都得到尊重
- Graph 搜索过滤掉仅内容匹配的项目；过滤后空页面仍可继续分页
- 浏览器关闭设置/详情弹窗后不再因迟到请求跳转或显示旧数据
- 定期轮询不会无限延长八小时会话期限
